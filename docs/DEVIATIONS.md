# Deviations from `docs/requirements.md`

Each entry: what the spec asked for, what was implemented, and why.

| # | Spec | Implemented | Why |
|---|---|---|---|
| 1 | `MaxFunctionInvocationIterations` | `HarnessAgentOptions.MaximumIterationsPerRequest` | That is the actual option name in Harness 1.20.0 (see `docs/API_NOTES.md`). The config key stays `Agent:MaxFunctionInvocationIterations`. |
| 2 | Build the model client with `Azure.AI.OpenAI` (`AzureOpenAIClient`) | `OpenAI.OpenAIClient` with `OpenAIClientOptions.Endpoint` pointed at the Foundry / Azure OpenAI `/openai/v1` endpoint, plus an `api-key` header policy | `Azure.AI.OpenAI` only ships as a prerelease that tracks the same `OpenAI` package, and the spec allows prerelease only for the shell package. The v1 endpoint is the documented way to use the plain OpenAI client against Azure with a key. `Foundry:UseV1Path` still controls the path. |
| 3 | `FluentAssertions` | `Shouldly` | FluentAssertions 8.x moved to a commercial (Xceed) licence; Shouldly is BSD-3. The spec explicitly allows this fallback. |
| 4 | Console exporter when `OpenTelemetry:OtlpEndpoint` is empty | File span exporter (`logs/traces-*.jsonl`) plus an in-memory ring buffer shown by `/traces`; the console exporter is opt-in via `OpenTelemetry:ConsoleExporter` | The console exporter writes raw span JSON to stdout in the middle of the streamed agent output and made the terminal UX unreadable. |
| 5 | `ScriptedChatClient` lives under `tests/…/Fakes/` | Lives in `src/ProcurementCopilot.Testing` and is referenced by the tests **and** by the console `--fake` mode | The console needs the fake for the offline demo; test projects cannot be referenced from `src`. |
| 6 | Session persistence test: "3 tool calls, 3 writes" | Asserts one store write per model call: 3 tool calls produce 4 model calls and 4 writes | A run with 3 tool calls needs a 4th model call to produce the final answer; `writes == modelCalls` is the precise statement of "written after each model call". |
| 7 | `check_vendor_compliance` = "sanctions list + certifications" | Also records the compliance *disposition* (`Flagged`) in session state; drafting a clarification upgrades it to `ClarificationRequested` | The loop evaluator needs a persisted disposition per compliance hit; flagging is the default disposition. |
| 8 | Sessions default under `%LOCALAPPDATA%/ProcurementCopilot/sessions/` | Same, resolved with `Environment.SpecialFolder.LocalApplicationData` so it works on Linux/macOS too | Cross-platform. |
| 9 | Responses client | Uses `AsIChatClientWithStoredOutputDisabled` (store=false) by default, switchable with `Foundry:StoreResponses` | With server-side storage the harness history/compaction pipeline has nothing to compact; keeping history in-process is what makes §4.2/§4.3 demonstrable. |
| 10 | Shell tool name `shell` in `RequireApprovalFor` | The confined shell tool is registered as `shell` (not the package default `run_shell`) | Keeps `Security:ApprovalPolicy:RequireApprovalFor` the single source of truth without a name alias. |
| 11 | `xunit` + `coverlet.collector` with `dotnet test --collect:"XPlat Code Coverage"` | xunit v3 on the Microsoft.Testing.Platform runner (`global.json` → `"test": { "runner": "Microsoft.Testing.Platform" }`) with `Microsoft.Testing.Extensions.CodeCoverage` and `dotnet test --solution … --coverage --coverage-output-format cobertura` | The .NET 10 SDK refuses to run xunit v3 through the legacy VSTest path, and `coverlet.collector` is a VSTest data collector. The Microsoft coverage extension is free (Microsoft Software License, not OSS). Source-generated JSON contexts are marked `[ExcludeFromCodeCoverage]` so the targets measure hand-written code. |
| 12 | Allowed workspace extensions `.md .txt .json .csv` | Adds `.jsonl` | The audit trail (`approvals.jsonl`, `actions.jsonl`) is written through the same `WorkspacePathPolicy`. |
| 13 | `Azure.AI.OpenAI` types in the factory | See #2; additionally responses are created with `store=false` (`AsIChatClientWithStoredOutputDisabled`) unless `Foundry:StoreResponses=true` | Keeps history in-process so per-call persistence and compaction are observable. |
| 14 | `ProcurementCopilot.sln` | `ProcurementCopilot.slnx` (the .NET 10 SDK's default solution format) | `dotnet new sln` on the .NET 10 SDK creates `.slnx`; all `dotnet` commands accept it. |
| 15 | Coverage via `dotnet test --collect` | `coverage.runsettings` passed with `--coverage-settings <absolute path>` | The Microsoft.Testing.Platform coverage extension resolves the path from each test executable's directory and rejects settings files that contain XML comments with angle brackets; the verify scripts pass the absolute path and the file has no comment. |
